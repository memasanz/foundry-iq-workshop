# Workshop overview

| Notebook | What you will do |
|---|---|
| [01 - Web IQ APIs](notebooks/01-web-iq-apis.ipynb) | Call Web Search, Browse, News, Images, Videos and Auto directly; inspect results, source attribution and citations. |
| [02 - Foundry agent + Web IQ](notebooks/02-foundry-web-iq-agent.ipynb) | Discover Web IQ MCP tools, create a Foundry connection, and build an agent that uses Web IQ to answer questions with sources. Inspect tool calls and approve tool use. |
| [03 - Foundry agent + Web IQ toolbox](notebooks/03-foundry-web-iq-toolbox.ipynb) | Create a toolbox exposing Web IQ, connect a Foundry agent to it, and compare with notebook 02's direct connection. |
| [04 - Blob indexer and skills](notebooks/04-blob-indexer-skills.ipynb) | Use an indexer to chunk and embed Blob documents, then compare keyword, vector, hybrid and semantic-ranked search. |
| [05 - Chunk, embed and push](notebooks/05-push-chunks-vectors.ipynb) | Chunk and embed the same files in Python, push to a separate index through REST, and compare with the indexer approach. |
| [06 - SharePoint indexed ingestion](notebooks/06-sharepoint-indexed.ipynb) | Index a test SharePoint library with document-level permissions, then test access using Entra users/groups and native SharePoint groups. |
| [07 - SharePoint remote retrieval](notebooks/07-sharepoint-remote.ipynb) | Query SharePoint through a remote knowledge source and the Copilot Retrieval API, without copying content into a Search index. |

## Prepare for the workshop

**Suggested deployment region: East US (`eastus`).** Central US (`centralus`) does not currently support Content Understanding, and East US 2 (`eastus2`) is currently capacity-constrained for new AI Search deployments. East US supports both services, so we recommend deploying Foundry, AI Search and Storage together there; Web IQ stays global. APIM is not provisioned by Bicep; notebook 09 uses an existing gateway, which can remain in its current region. Verify regional capacity and model quota before class. Changing this default does not move existing resources.
