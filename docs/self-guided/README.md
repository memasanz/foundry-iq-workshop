# Learning on your own

[Workshop home](../../README.md) | [Choose your labs](../labs/README.md)

Follow the facilitator setup once, then use the participant instructions.
You need your own eligible Azure subscription and access to the services you choose.

1. **[Choose your labs](../labs/README.md).** Start with lab 01 for direct Web IQ APIs,
   or select a track before setting up resources. Python covers labs 01-15; C# currently covers labs 01-06 and 08-13.
2. **[Prepare your environment](../facilitators/README.md).** Complete only the setup required
   by those labs. If you already have a working Web IQ profile/API key, lab 01 needs no
   additional Azure deployment or sign-in. For your own new resources, follow the
   [beginner deployment guide](../../infra/README.md) and [Web IQ onboarding](../facilitators/README.md#3-complete-web-iq-onboarding).
3. **[Set up your code](../participants/README.md).** Choose Python, the supported .NET 10
   console app, or the optional legacy Polyglot Notebook, then run your selected exercises.
4. **[Clean up when finished](../reference/README.md#cleanup).** Stop paid services and
   revoke workshop-only credentials. Closing an editor does not stop Azure charges.

An Azure subscription role does not grant tenant administrator authority.
For SharePoint lab 07, arrange the [administrator approval](../facilitators/sharepoint.md#administrator-handoff-approve-permissions-and-site-read-once);
for remote SharePoint lab 08, verify licensing or enabled Retrieval API billing.
Do not weaken tenant security policies to complete an exercise.

Use the [preparation matrix](../../PREPARE-FOR-WORKSHOP.md) for required roles and service identities,
and the [reference guide](../reference/README.md) for costs, troubleshooting and live-validation limits.
